# Virtual Agora

인물 두 명과 주제를 고르면, 시공간을 넘어선 대화를 만들어주는 해커톤 데모입니다.
AI 시대의 직업 문제를 서로 다른 철학으로 충돌시키고, 사용자가 자신의 판단 기준을
발견하도록 돕는 인터랙티브 사고 실험을 목표로 합니다.

인물 카드는 제공받은 초상 일러스트 시트를 인물별로 고해상도 크롭한 `assets/*.png`를
사용합니다. 이름표와 중복 이미지는 제외하고 얼굴 원형 프레임을 보존했으며, 앱의 모든
프로필과 메신저 아바타에서 동일하게 사용합니다. 모든 프로필은 같은 원형 스타일로
표시됩니다. 추천 조합인
이순신 × 스티브 잡스, 세종대왕 × 공자에는 큐레이션된 데모 대화가 연결되어
있어 API 키 없이도 발표 시나리오를 재현할 수 있습니다. 대표 조합인 이순신 × 스티브 잡스,
소크라테스 × 니체, 부처 × 쇼펜하우어는 인물별 전용 24턴 큐레이션 대화를 제공하고,
세종대왕 × 공자는 리더십과 공공성에 초점을 둔 대표 조합으로 구성했습니다. 오프라인 대화는 24턴으로,
각 인물의 공개적으로 알려진 철학·대표 사례·말투를 반영한 두 번째 논의 라운드까지 제공합니다.

## 리서치 기준

인물 데이터는 공개 백과사전과 역사·전기 자료를 교차 확인해 요약했습니다. 니체는
『차라투스트라는 이렇게 말했다』·『즐거운 학문』의 자기 극복과 가치 창조를, 쇼펜하우어는
『의지와 표상으로서의 세계』의 욕망·고통 분석과 연민의 윤리를 중심으로 반영했습니다.
결과는 역사적
기록의 재현이 아니라, 확인 가능한 사건과 사상을 소재로 한 창작 대화입니다. 특히 종교적
인물은 신앙을 단정하거나 설교하지 않고 전승된 가르침을 존중하는 방식으로 표현합니다.

## 실행

```powershell
python -m pip install -r requirements.txt
streamlit run app.py
```

API 키 없이도 로컬 데모 대본이 생성됩니다. 실제 LLM을 연결하려면 `.env.example`의 값을 환경 변수로 설정하세요.

## 데모 시나리오

1. `랜덤 조합으로 시작` 또는 `대화 시작하기`를 누릅니다.
2. 인물, 주제, 톤을 선택하고 `대화 생성하기`를 누릅니다.
3. 결과의 케미 점수와 대본을 확인한 뒤 톤을 바꿔 다시 생성합니다.
4. `결과 복사하기` 또는 `결과 텍스트 저장`으로 공유합니다.

랜딩의 `인물에게 질문하기`는 베타용 1:1 대화 모드로 바로 진입합니다.
대화 전에는 예상 관점을 선택하고, 대화 후에는 생각이 바뀌었는지 다시 선택합니다. 결과
화면에서는 각 인물의 주장, 충돌 지점, 공통 접점, 관점 카드를 확인할 수 있습니다.
베타 데모에서는 사용자가 임의의 인물·주제·질문을 입력하는 기능을 제공하지 않습니다.
사전 구성된 인물과 AI·직업 질문만 지원해 발표 환경에서 답변의 품질과 일관성을
우선합니다.

역사적 인물에 대한 결과는 창작물이며 역사적 사실 기록이 아닙니다.
