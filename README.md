# Virtual Agora

## 프로젝트 한 줄 소개
AI가 정답을 주는 시대가 아니라, 질문을 더 깊게 만드는 시대.

Virtual Agora는 과거의 인물과 오늘의 고민을 연결하며, 사용자가 더 나은 질문을 던지고 더 깊이 생각하게 만드는 인문형 AI 대화 플랫폼입니다.

## 서비스 철학
사람은 정보보다 ‘질문’이 필요합니다.

우리는 단순히 빠른 답변을 제공하는 AI가 아닙니다. 우리는 사용자가 지금 어떤 고민을 안고 있는지, 왜 흔들리는지, 어떤 관점으로 다시 바라봐야 하는지를 이해할 수 있도록 돕는 서비스입니다.

과거의 지혜를 현재의 삶에 연결하고, 역사 속 인물의 관점을 통해 자기 성찰을 시작하게 만드는 것이 Virtual Agora의 핵심 가치입니다.

## 핵심 기능

- **인물 대화**: 역사 속 인물과 현대의 이슈를 연결한 2인 대화 경험
- **인물에게 질문하기**: 인물의 관점으로 직접 질문하고, 후속 질문을 이어가는 구조
- **아고라 매거진**: AI, 창작, 진로, 관계, 권력, 공동체 등 현대 이슈를 역사적 시선으로 재해석
- **평행 시절**: 사용자의 나이대, 감정, 고민을 기반으로 과거 인물과 지금의 삶을 연결해주는 기능
- **사고 전환 확인**: 대화 전후의 관점 변화와 가치 판단의 전환을 확인
- **오프라인 데모**: API 키 없이도 기본 대화와 시나리오를 통해 바로 사용할 수 있는 구조

## 다루는 주제

AI와 일자리, 인간만의 역할, 생성형 AI와 창작, 채용 AI의 공정성, AI 시대의 리더십을 넘어

- 진로와 정체성
- 관계와 소속감
- 결혼과 자유
- 성취와 의미
- 불안과 막막함
- 가치관과 삶의 방향

까지 인간의 삶 전반을 다룹니다.

모든 대화는 역사적 인물의 공개적으로 알려진 사상과 사례를 참고해 구성한 AI 창작 시뮬레이션입니다. 실제 인물의 발언이나 공식 입장을 대변하지 않으며, 현재의 질문과 연결해 재구성한 창작 콘텐츠입니다.

## 로컬 실행

```powershell
python -m pip install -r requirements.txt
streamlit run app.py
```

실행 후 로컬 주소에서 확인할 수 있으며, API 키 없이도 데모 형태로 사용할 수 있습니다.

## Streamlit Community Cloud 배포

1. GitHub 저장소에 `app.py`, `requirements.txt`, `assets/`를 포함해 push합니다.
2. [Streamlit Community Cloud](https://share.streamlit.io/)에서 **Deploy an app**을 선택합니다.
3. 아래 값을 입력합니다.

```text
Branch: main
Main file path: app.py
```

배포 후 생성되는 서비스 주소를 프로토타입 링크로 사용할 수 있습니다.

실시간 모델을 연결할 때만 Secrets에 아래 값을 추가합니다. 미설정 상태에서는 로컬 큐레이션 대화가 기본으로 사용됩니다.

```text
OPENAI_API_KEY = "..."
OPENAI_BASE_URL = "https://api.openai.com/v1"
OPENAI_MODEL = "gpt-4o-mini"
```

## 추천 시연 순서

1. 입장 페이지에서 **아고라 입장하기** 선택
2. **인물 대화**에서 인물과 주제 선택
3. 질문 전후의 관점을 확인하며 대화 생성
4. 24턴 대화, 충돌 지점, 공통 접점, 성찰 결과 확인
5. **인물에게 질문하기**와 **아고라 매거진**으로 확장 경험
6. 마지막으로 **평행 시절**에서 현재의 감정과 고민을 인물의 시대와 연결해 이해

## 기술 스택

- Python
- Streamlit
- OpenAI-compatible API 연동
- 생성형 AI 기반 대화 큐레이션
- 역사적 맥락 정보 구조화

## 품질 관리 및 콘텐츠 가이드

- 역사적 인물의 실제 발언을 사실처럼 제시하지 않음
- 창작형 해석과 사실 기반 기록을 구분해 제공
- 사용자의 감정과 고민을 지나치게 단정하지 않고, 인간적 맥락으로 해석
- 현대 문제와 역사적 인물을 연결하는 과정에서 사실적 한계를 명확히 유지

## 저작권 및 콘텐츠 안내

인물 이미지는 프로젝트에 포함된 에셋을 사용하며, 인물 대화와 매거진 코멘트는 공개 자료를 참고한 AI 창작 콘텐츠입니다. 실제 인물의 발언이나 공식 입장을 대표하지 않습니다.
